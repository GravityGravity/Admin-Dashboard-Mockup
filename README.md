# Admin Dashboard Mockup
This is a admin dashboard mock up to practice CSS grid layouts

**Live Demo:** [View the site][(https://gravitygravity.github.io/Admin-Dashboard-Mockup/)
 
![Admin Dashboard Screenshot](./imgs/screenshot.png)
 
## Features
 
- CSS Grid page layout with a header, sidebar, and main content area
- Header with search bar, notifications icon, and user profile
- Sidebar navigation with icon links
- Projects section with a two-column card grid
- Announcements and Trending panels
- Nested CSS and custom-property-based shadows
